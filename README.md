# Portfólio Pessoal - Vimi TT

Este é o código-fonte do meu portfólio acadêmico, desenvolvido originalmente utilizando HTML/CSS (Material Design 3) e agora escalado e otimizado utilizando **AstroJS** e **React**.

## Tecnologias Utilizadas
- **AstroJS**: Para um build ultra rápido (Zero JS na renderização inicial), resultando num HTML totalmente estático, performático e amigável para SEO.
- **Integração com GitHub API**: Durante a compilação do site (build-time), ele busca automaticamente os projetos mais recentes da minha conta do GitHub e os exibe.
- **Material Design 3**: A interface é inspirada nos guias mais atuais do Google (Material You), utilizando uma tipografia moderna, componentes como Cards, Buttons, Chips e paleta baseada num design limpo e acessível.
- **Hospedagem GitHub Pages**: Preparado para ser lançado através de um ambiente `.github.io`.

## Como Executar Localmente

### Instale as dependências
```bash
npm install
```

### Rode o servidor de desenvolvimento local
```bash
npm run dev
```

### Compile para produção (SSG)
```bash
npm run build
```
